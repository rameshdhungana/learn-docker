# Task 15 — Inspect and debug

**Level 6 — Cleanup & hygiene**

## What to do

- Use `docker inspect <container>` and `docker logs <container>` on one of your containers.
- Run a one-off command in a running container: `docker exec -it <container> sh`.

## Commands to learn

- `docker inspect`
- `docker logs`
- `docker exec -it`

## Check

- You can see container config, logs, and run a shell inside it.
