# Task 14 — Clean up

**Level 6 — Cleanup & hygiene**

## What to do

- Remove all stopped containers: `docker container prune`.
- Remove unused images: `docker image prune -a` (careful: removes all unused images).
- Remove unused volumes: `docker volume prune`.

## Commands to learn

- `docker container prune`
- `docker image prune -a`
- `docker volume prune`
- When to use `-f` or `-a`

## Check

- Unused resources are removed; disk usage drops.
