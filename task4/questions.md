# Task 4 — Name and remove

**Level 1 — Basics**

## What to do

- Run a container with a custom name: `docker run --name my-nginx nginx` (then stop it with Ctrl+C or `docker stop my-nginx`).
- Remove the container: `docker rm my-nginx`.

## Commands to learn

- `docker run --name`
- `docker stop`
- `docker rm`

## Check

- Container ran with your chosen name; after remove it no longer appears in `docker ps -a`.
