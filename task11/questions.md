# Task 11 — Compose two services

**Level 4 — Networking**

## What to do

- Create a `docker-compose.yml` with a web service (e.g. nginx) and an app service (e.g. a small API or another nginx). Put them on the same custom network and have one call the other by service name.

## Commands to learn

- `docker compose up`
- Service names as hostnames in Compose

## Check

- Both services run; one can reach the other by service name.
