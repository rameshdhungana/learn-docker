# Task 6 — Add a small app

**Level 2 — Images & Dockerfile**

## What to do

- Create a minimal static file (e.g. `index.html`) and a `Dockerfile` that uses `nginx:alpine` and copies `index.html` into `/usr/share/nginx/html/`.
- Build and run with `-p 8080:80`. Open http://localhost:8080 in your browser.

## Commands to learn

- `COPY` in Dockerfile
- Port mapping `-p host:container`

## Check

- Your page loads in the browser on port 8080.
