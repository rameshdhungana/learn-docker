# Task 5 — Build a simple image

**Level 2 — Images & Dockerfile**

## What to do

- In this folder (or a subfolder), create a `Dockerfile` that:
  - Uses `FROM alpine`
  - Runs `echo "Hello from my image!"` via `CMD`.
- Build: `docker build -t my-hello .`
- Run: `docker run my-hello`

## Commands to learn

- `docker build -t <name> .`
- `FROM`, `CMD` in Dockerfile

## Check

- Output is "Hello from my image!".
