# Task 7 — Multi-stage build (optional)

**Level 2 — Images & Dockerfile**

## What to do

- Create a Dockerfile that builds a simple Go or Node app in one stage and copies only the binary/files into a minimal final image (e.g. `alpine`). Run the final image.

## Commands to learn

- Multi-stage `FROM` and `COPY --from=`

## Check

- Final image is smaller; app runs from the minimal image.
